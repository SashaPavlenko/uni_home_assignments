# Java

- [java_course](java_course) - labs from a university Java course: generic stack and month diary with JUnit tests, tasks on collections (synonyms dictionary, bus routes, name history), Stream API, and a multithreaded TCP echo server with a client.
- [BiBiFi Art Gallery log](BiBiFi%20Art%20Gallery%20log) - team project from the Secure Software Engineering course: command-line tools `logappend` and `logread` that keep an art gallery's visitor log in an encrypted file (PBKDF2 key from a token, AES-CBC, JSON via Gson), validate all input and reject implausible events.
- [Stack realization](Stack%20realization) - generic array-based stack `Stack<T>` with overflow / empty-stack exceptions and JUnit tests.
