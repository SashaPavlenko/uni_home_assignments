Errors.
Error code 1: an already initialized matrix is passed to the function.
Error code 2: an uninitialized matrix is passed to the function.
Error code 3: division by zero.
Error code 4: after deleting a row or a column the matrix became singular.

Matrix examples:
rows = 4
cols = 4
Matrix:
    1   -1    0    5
    0    0    0    0
    5    4    3    2
   -1   -2   -3   -4
