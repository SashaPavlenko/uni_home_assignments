# C++

- [cpp_course](cpp_course) - labs, individual tasks and tests from a two-semester university C++ course: procedural programming (arrays, matrices, strings, files) and OOP (own list / array / tree classes, inheritance, polymorphism, unit tests).
- [Breadth_first_search](Breadth_first_search) - breadth-first graph traversal on an adjacency matrix read from a file, with custom file exceptions.
- [Minimum_spanning_tree](Minimum_spanning_tree) - graph class with Prim's algorithm for the minimum spanning tree and BFS, run on input files.
- [Paralleled_multiplication_matrix](Paralleled_multiplication_matrix) - matrix multiplication parallelized with OpenMP, timed against the sequential version with 1-4 threads.
- [Set_based_on_recursive_tree_realization](Set_based_on_recursive_tree_realization) - set class based on a recursive binary tree.
