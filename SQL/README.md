# SQL

Queries and stored procedures from a databases course (Firebird dialect).

- `Example_of_join.sql` - inner joins on employee / department / job / project tables.
- `Example_of_subqueries.sql` - scalar, derived-table and correlated subqueries.
- `Procedure_example_1.sp`, `Procedure_example_2.sp` - stored procedures (`for select ... suspend`) over a warehouse database (goods, agents, warehouses, operations).
- `Procedure_call.sql` - calls of the procedures.
