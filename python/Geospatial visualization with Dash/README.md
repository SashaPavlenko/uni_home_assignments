# Geospatial visualization with Dash (Visual Data Analysis, University of Bonn)

`geospatial_dash_solution.ipynb`: choropleth maps of German districts with `geopandas` (administrative areas, highlighting Bonn, wind power generation per district with an outlier-robust colour scale) and an interactive `Dash` app with callback-driven scatter plots that can be added, deleted and inspected for min/max values. Also contains short answers on grid types (rectilinear, uniform, curvilinear).

`task_description.pdf` - assignment; `solution.pdf` - exported solution. The shapefiles and `power_generation.csv` (about 55 MB) are not included.
