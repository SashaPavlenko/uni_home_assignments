- [CIFAR-10 classification](CIFAR-10%20classification) - improving a LeNet-5 in PyTorch (pooling, dropout, batch normalization, residual CNN with augmentation), up to 80.74% test accuracy. [Technical report (PDF)](CIFAR-10%20classification/technical_report.pdf)

  ![Test accuracy over epochs, task 5 variants](CIFAR-10%20classification/accuracy_task5.png)

- [Geospatial visualization with Dash](Geospatial%20visualization%20with%20Dash) - choropleth maps of German districts with `geopandas` and an interactive `Dash` app. [Solution (PDF)](Geospatial%20visualization%20with%20Dash/solution.pdf)
- [Isosurfaces and volume visualization](Isosurfaces%20and%20volume%20visualization) - CT head data in ParaView and VTK (slices, nested isosurfaces), plus theory on grids, finite differences and Marching Cubes. [Solution (PDF)](Isosurfaces%20and%20volume%20visualization/solution.pdf)

  ![Nested skin and bone surfaces](Isosurfaces%20and%20volume%20visualization/screenshots/face.png)

- [NumericalAnalys](NumericalAnalys) - a collection of numerical methods labs: root finding, quadrature, ODE solvers and interpolation.
- [Solving differencial equations](Solving%20differencial%20equations) - two numerical methods labs: Newton and Hermite interpolation, and Euler / Heun / Runge-Kutta solvers for Cauchy problems.
- [Fractals generation](Fractals%20generation) - the Sierpinski triangle drawn with the "chaos game" in `turtle`.
