# Numerical methods labs (Python)

Two labs from a numerical methods course. The task statements (in Russian) are in `task_description.pdf` of each folder.

- `lab2_interpolation` - Newton interpolation polynomial via finite differences and Hermite interpolation (multiple nodes) via divided differences, built with `numpy`/`sympy` and plotted with `matplotlib`.
- `lab5_cauchy_problem_ode` - Cauchy problem for ODEs: explicit Euler, implicit Euler, Heun and third-order Runge-Kutta methods (coefficients found by solving the order-condition system), error norm against the exact solution; Runge-Kutta for a third-order ODE rewritten as a first-order system. `task1_*` / `task2_*` are the two tasks as scripts and notebooks.
